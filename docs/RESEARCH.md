# 研究设计

研究对象是持久、可外部干预的战略状态，而非单独增加循环记忆或任务层。Preference 为具名、非负战略优先级；IntentState 在其上增加承诺期、年龄、置信度与生命周期。

## 假设与比较

| 假设 | 识别方式 |
| --- | --- |
| H1：Preference 具有可测的因果控制效应 | 剂量、交叉效应、干预遵从与基础能力 |
| H2：持久 Intent 有超越瞬时条件和记忆的价值 | stepwise、固定承诺期、学习生命周期与不同承诺期 |
| H3：Manager 分配和可见反馈有助于任务控制 | Manager、成员分配、反馈与置信度消融 |
| H4：Intent 是有效的 RL 和群体接口 | 同等环境帧与计算资源下的学习曲线、覆盖和鲁棒性 |

三方主比较为 flat recurrent、direct Task without Intent、persistent Intent。补充前馈、外部/学习 Preference、不同生命周期与有无反馈等对照，共用底层观测、动作、合法性与执行语义。

## 实验范围

| 实验 | 比较 |
| --- | --- |
| E1 | Preference 干预的目标效应、交叉效应与基础能力代价 |
| E2 | direct Task、stepwise Preference、固定承诺期与学习生命周期 |
| E3 | 外部固定/oracle 参照、学习 Manager、学习 Manager 加 override |
| E4 | 有执行反馈与无反馈 |
| E5 | 匹配环境帧和计算资源的 flat、direct Task 与 Intent RL |
| E6 | 匹配总资源的普通联盟与 Intent 专门化联盟 |

执行时需固定数据、环境、参数规模、种子、训练资源和模型选择规则；研究接口实现并不意味着这些实验已经完成。

当前限定 ZvZ。主要指标包括各头监督覆盖与准确率、在线合法性、任务可见完成率、干预效应、置信度校准、学习效率与独立对手评估。观察不足与不可定义指标显式报告，不替换为成功或零值。

当前未提供正式训练结果，也未证明 Intent 优于匹配对照。真实引擎的长局采集、BC 泛化、PPO 稳定性及目标研究效应仍需验证。
